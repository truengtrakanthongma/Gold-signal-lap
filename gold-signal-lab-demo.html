คำถาม: ถ้าเอาข่าวมาผสมกับกราฟ จะคาดการณ์ได้แน่นอนกว่าเดิมไหม ปุ่มนี้ตอบด้วยการวัด ไม่ใช่ด้วยความรู้สึก — ดึงข่าวย้อนหลังในช่วงเวลาเดียวกับแท่งเทียนที่โหลดมา จัดเรียงตามเวลาแบบหน่วง 15 นาที (กันการใช้ข่าวที่ตอนนั้นยังไม่มีใครรู้) แล้วแบ่งไม้เทรดเป็นสามกลุ่ม: ข่าวหนุน · ข่าวค้าน · ข่าวเงียบ แล้วเทียบผลกันตรง ๆ

ถ้าตัดไม้ที่ข่าวค้านออกแล้วผลดีขึ้นอย่างมีนัย ระบบจะบอกว่าใช้ได้ ถ้าไม่ ก็จะบอกตรง ๆ ว่าไม่ช่วย

ให้ระบบศึกษาตลาดนี้เอง แล้วปรับกลยุทธ์ตามที่เรียนรู้

ค่าตั้งต้นทุกตัว (คะแนนขั้นต่ำ 35, จุดตัดขาดทุน 1.5 เท่า ATR, เป้า 2 เท่า) เป็นค่ากลาง ๆ ที่ตั้งไว้ล่วงหน้า ไม่ได้ดูตลาดที่คุณโหลดมาเลย ปุ่มนี้จะให้ระบบศึกษาตลาดนี้เอง: แบ่งข้อมูลเป็นหลายช่วงตามเวลา แล้วจูนใหม่ทุกช่วงโดยดูได้แค่อดีตของช่วงนั้น เอาผลทุกช่วงมาต่อกันเป็นผลจริงของ "ระบบที่ปรับตัวเอง" แล้วเทียบกับค่าคงที่บนช่วงเดียวกัน — จึงตอบได้ว่าการปรับตัวเองช่วยจริงหรือไม่

ตรวจสอบน้ำหนักปัจจัย — น้ำหนักที่ตั้งไว้ถูกจริงไหม?

คะแนนสัญญาณมาจากการถ่วงน้ำหนัก 12 ปัจจัย (เส้นค่าเฉลี่ย 16, ความแรงแนวโน้ม 12, …) ตัวเลขชุดนี้ตั้งจากตำราและประสบการณ์ ไม่ใช่จากข้อมูลของคุณ ปุ่มนี้จะ เรียนรู้น้ำหนักใหม่จากผลเทรดจริงในช่วงแรกของข้อมูล แล้ว เอาไปสอบกับช่วงหลังที่ตอนเรียนรู้ไม่เคยเห็น ถ้าสอบไม่ผ่าน ระบบจะไม่ให้ใช้ — ไม่ว่าตัวเลขตอนเรียนรู้จะสวยแค่ไหน

สถิติราคาช่วงที่โหลดมา

ทดสอบแหล่งราคาทอง — อันไหนใช้ได้จากเครื่องคุณ

ราคาทองคำสปอต (XAU/USD) เป็นข้อมูลมีลิขสิทธิ์ เจ้าที่แจกฟรีจึงต้องขอให้สมัครคีย์เสมอ ส่วนที่ฟรีจริงไม่ต้องใช้คีย์คือโทเคนที่หนุนด้วยทองคำในตลาดคริปโต ซึ่งวิ่งเกาะทองจริงแต่ไม่เท่ากันเป๊ะ

จุดที่คนมักมองข้าม: คู่ที่เทียบกับ USD จริง (Kraken, Bitfinex) ใกล้ราคาทองมากกว่าคู่ที่เทียบ USDT (Binance, OKX) เพราะตัดความคลาดเคลื่อนของ USDT ออกไปอีกชั้น

แต่ละเจ้าจะยอมให้เว็บอื่นเรียกหรือไม่ และเครือข่ายบ้านคุณบล็อกอันไหน ผมทดสอบแทนไม่ได้ — ปุ่มนี้จะยิงทดสอบจากเบราว์เซอร์คุณเองแล้วรายงานว่าอันไหนใช้ได้จริง

อยากได้ราคาทองคำสปอตจริง (XAU/USD)

ค่าเริ่มต้นใช้ PAXG ซึ่งเป็นโทเคนอิงทองคำ ราคาวิ่งเกาะทองจริงแต่ไม่เท่ากันเป๊ะ ถ้าเอาไปเทียบกับกราฟทองของโบรกเกอร์แล้วตัวเลขไม่ตรง สาเหตุคือตรงนี้

  1. สมัครฟรีที่ twelvedata.com (แผนฟรีพอใช้งาน)
  2. คัดลอก API key มาวางในช่องข้างล่าง
  3. เปลี่ยน "แหล่งข้อมูล" ด้านบนเป็น Twelve Data XAU/USD

แผนฟรีจำกัด 8 คำขอ/นาที ระบบจึงดึงราคาใหม่ทุก 15 วินาที (ไม่ใช่เรียลไทม์เท่า Binance) และ API key เก็บอยู่ในเบราว์เซอร์ของคุณเท่านั้น ไม่ได้ส่งไปไหน

ระบบนี้ทำงานอย่างไร

  1. ดึงราคาเรียลไทม์ — ค่าเริ่มต้นใช้ PAXG/USDT บน Binance ผ่าน WebSocket (โทเคนหนุนด้วยทองคำจริง 1 เหรียญ = 1 ทรอยออนซ์ เก็บในตู้นิรภัยลอนดอน) ราคาจึงวิ่งเกาะ XAU/USD และมีข้อมูล 24 ชม. ไม่ต้องใช้ API key ถ้าต้องการ XAU/USD ของจริง ให้ใส่ API key ของ Twelve Data ในแท็บตั้งค่า
  2. คำนวณตัวชี้วัด — EMA20/50/200, RSI, MACD, Bollinger, ATR, ADX/DI, Stochastic, OBV, VWAP, swing pivot, แนวรับ-แนวต้านจากจุดกลับตัวจริง และรูปแบบแท่งเทียน
  3. ให้แต่ละปัจจัยโหวต — ทุกปัจจัยให้ทิศทาง (+ซื้อ/−ขาย) และความแรง 0–1 พร้อมเหตุผลภาษาไทย รวมกันเป็นคะแนน −100 ถึง +100
  4. ตรวจสอบข้ามกรอบเวลา — ถ้ากรอบเล็กสวนกรอบใหญ่ คะแนนจะถูกตัดลง 40%
  5. แปลงเป็นแผนเทรด — SL วางจาก ATR และ swing ล่าสุด (กว้างพอไม่ให้ noise เขี่ยออก) เป้าหมายคิดเป็น R และปรับให้ไม่ชนแนวต้าน/แนวรับใหญ่
  6. วัดความน่าจะเป็นจากสถิติจริง — กดปุ่มทดสอบย้อนหลัง ระบบจะเดินกฎเดียวกันนี้ทุกแท่งในอดีต แล้วนับว่า "แตะ 1R ก่อนโดน SL" กี่ครั้ง ตัวเลข % ที่แสดงคือสถิติจริงของกฎชุดนี้ ไม่ใช่ตัวเลขที่ตั้งขึ้นมาลอย ๆ

ข้อจำกัดที่ต้องรู้ก่อนใช้เงินจริง

  • Backtest ใช้ข้อมูลระดับแท่งเทียน ไม่ใช่ tick — ถ้าแท่งเดียวแตะทั้ง SL และ TP ระบบนับเป็น "แพ้" เสมอ (อนุรักษ์นิยม แต่ก็ยังไม่เท่าการเทรดจริง)
  • ไม่ได้รวมค่า swap ข้ามคืน ค่าคอมมิชชัน หรือการที่สเปรดถ่างตอนข่าว — ของจริงต้นทุนสูงกว่านี้
  • ตัวเลขอัตราชนะมาจากข้อมูลเท่าที่โหลดมา (ไม่กี่ร้อยแท่ง) ตลาดเปลี่ยนพฤติกรรมได้ อดีตไม่รับประกันอนาคต
  • PAXG ≠ XAU/USD เป๊ะ ๆ มีส่วนต่างพรีเมียม/ดิสเคานต์ได้ 0.1–1% และช่วงตลาด spot ปิด ราคาจะเคลื่อนตาม flow คริปโต
  • ระบบนี้เป็นเครื่องมือช่วยตัดสินใจและให้ข้อมูลประกอบ ไม่ใช่คำแนะนำการลงทุน การเทรดทองมีเลเวอเรจสูงและขาดทุนเกินเงินต้นได้

วิธีใช้ให้ได้ผลที่สุด

  1. เลือกกรอบเวลาที่ตรงกับสไตล์ตัวเอง (สแกล์ป 5m · เดย์เทรด 15m–1h · สวิง 4h–1d)
  2. กด "ทดสอบกฎกับข้อมูลจริงย้อนหลัง" ก่อนเสมอ ดูว่าคะแนนขั้นต่ำระดับไหนให้อัตราชนะและค่าคาดหวัง (Expectancy) เป็นบวก แล้วค่อยตั้งเกณฑ์ตามนั้น
  3. ดูตาราง "อัตราชนะตามช่วงเวลา" เพื่อรู้ว่าควรเทรดชั่วโมงไหน — นี่คือส่วน "จังหวะ" ที่คนส่วนใหญ่มองข้าม
  4. เข้าเฉพาะไม้ที่คะแนนสูงและกรอบเวลาไปทางเดียวกัน อย่าไล่ราคาเมื่อ RSI ร้อนจัด
  5. ยึดขนาดไม้ตามช่อง "ความเสี่ยง/ไม้" เสมอ — ระบบคำนวณ lot ให้แล้วจากระยะ SL จริง
  6. เมื่อกำไรถึง 1R ให้ปิดครึ่งและเลื่อน SL มาที่ทุน (นี่คือสมมติฐานเดียวกับที่ backtest ใช้ ตัวเลขจึงตรงกับพฤติกรรมที่แนะนำ)
