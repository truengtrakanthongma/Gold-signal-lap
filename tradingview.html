ใส่ Gold Signal Lab ใน TradingView

กติกาเดียวกับเว็บแอป — ตามเทรนด์กราฟรายวัน รอราคาย่อบนกราฟ 4 ชั่วโมง · ได้ราคา XAUUSD จริงจากโบรกเกอร์คุณ ทดสอบย้อนหลังในตัว และแจ้งเตือนเข้ามือถือ

ข้อจำกัดที่ต้องรู้ก่อน: แอป TradingView บนมือถือไม่มี Pine Editor จึงวางโค้ดในแอปไม่ได้ ต้องวางผ่านเบราว์เซอร์ในโหมดคอมพิวเตอร์ ครั้งเดียว หลังจากนั้นใช้ในแอปได้ตามปกติ รวมถึงรับแจ้งเตือน
  1. กดปุ่ม คัดลอกโค้ดทั้งหมด ข้างบน
  2. เปิด Chrome (Android) หรือ Safari (iPhone) — ไม่ใช่แอป TradingView
  3. เปิดโหมดคอมพิวเตอร์:
    • Chrome → จุดสามจุดมุมขวาบน → ติ๊ก เว็บไซต์เดสก์ท็อป
    • Safari → ไอคอน ᴀA ซ้ายช่อง URL → ขอเว็บไซต์เดสก์ท็อป
  4. ไปที่ tradingview.com/chart แล้วเข้าสู่ระบบ (สมัครฟรีได้)
  5. ค้นหาสัญลักษณ์ XAUUSD แล้วเลือกกรอบเวลา 4 ชั่วโมง (4h)
  6. ล่างจอมีแถบ Pine Editor — แตะเพื่อกางขึ้นมา
    หมุนมือถือเป็นแนวนอนตรงนี้จะง่ายขึ้นมาก
  7. ลบโค้ดตัวอย่างที่มีอยู่ให้หมด แล้ววางโค้ดที่คัดลอกมา
  8. กด Save → ตั้งชื่อ Gold Signal Lab → กด Add to chart
  9. เสร็จแล้ว! ปิดโหมดเดสก์ท็อปได้ กลับไปใช้แอป TradingView ตามปกติ — สคริปต์จะอยู่ใน Indicators → My scripts เพิ่มลงกราฟได้เลย
  1. กดปุ่ม คัดลอกโค้ดทั้งหมด ข้างบน
  2. เปิด tradingview.com/chart แล้วเข้าสู่ระบบ
  3. ค้นหา XAUUSD เลือกกรอบเวลา 4 ชั่วโมง (4h)
  4. ล่างจอ กด Pine Editor
  5. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดที่คัดลอกมา
  6. กด Save ตั้งชื่อ แล้วกด Add to chart
  7. เปิดแท็บ Strategy Tester ล่างจอ เพื่อดูผลทดสอบย้อนหลังกับทองจริง

ตั้งแจ้งเตือนเข้ามือถือ

  1. บนกราฟที่ใส่สคริปต์แล้ว กดไอคอน นาฬิกาปลุก (Alert)
  2. ช่อง Condition เลือก Gold Signal Lab
  3. เลือกเงื่อนไข Any alert() function call
  4. ในแท็บ Notifications ติ๊ก Push notification
  5. กด Create — จากนี้สัญญาณจะเด้งเข้ามือถือเอง ไม่ต้องเปิดจอทิ้งไว้

อ่านผลทดสอบย้อนหลังยังไง

ในแท็บ Strategy Tester ดูสามตัวนี้พอ:
• Profit Factor — เกิน 1.0 คือกำไร ต่ำกว่าคือขาดทุน
• Total Closed Trades — ต่ำกว่า 30 ไม้ ยังสรุปอะไรไม่ได้ ให้ถือว่าเป็นแค่ตัวอย่าง
• Max Drawdown — เคยติดลบลึกสุดเท่าไร ถ้าคุณทนไม่ไหว ก็ใช้ระบบนี้ไม่ได้ ต่อให้สุดท้ายมันกำไร
ผลที่ควรเห็นโดยประมาณ (ทดสอบบนทองจริง 2022-2025): ราว 3-4 ไม้ต่อเดือน · ชนะราว 45% · Profit Factor ราว 1.5 ถ้าผลบนโบรกเกอร์คุณต่างไปมาก ให้เช็คว่าใช้กราฟ 4 ชั่วโมง และสัญลักษณ์ทองจริง (XAUUSD)
อย่าจูนค่าให้ผลสวยที่สุด — ค่าตั้งต้นคือค่าที่ทดสอบแล้ว และทนต่อการเปลี่ยนค่า การไล่ปรับจนกราฟกำไรสวยคือการฟิตกับอดีต ซึ่งมักพังทันทีที่ใช้จริง

โค้ดทั้งหมด

ถ้าปุ่มคัดลอกใช้ไม่ได้ กดค้างในกล่องนี้แล้วเลือกทั้งหมดเองได้

// © Gold Signal Lab — กติกาเดียวกับเว็บแอปและบอท Discord
// https://github.com/truengtrakanthongma/Gold-signal-lap
//
// กติกา (วัดบนทองจริง XAU/USD 2022-2025: 166 ไม้ ชนะ 45% เฉลี่ย +0.28R ต่อไม้ หลังหักต้นทุน กำไรทุกปี)
//  1. เทรนด์ใหญ่จากกราฟรายวัน (แท่งที่ปิดแล้ว):
//       ขาขึ้น = ราคาปิด > EMA50 และ EMA20 > EMA50 · ขาลง = กลับด้าน · นอกนั้นไม่เทรด
//  2. ใช้บนกราฟ 4 ชั่วโมง:
//       ขาขึ้น + ราคาปิดย่อลงใต้ EMA20 → ซื้อ · ขาลง + ราคาปิดเด้งเหนือ EMA20 → ขาย
//  3. เข้าที่ราคาเปิดแท่งถัดไป · ตัดขาดทุน 2 × ATR(14) · ทำกำไร 2 เท่าของที่เสี่ยง
//  4. ถือไม่เกิน 36 แท่ง (6 วัน) · ออกไม้แล้วพัก 6 แท่ง (24 ชม.) · ถือทีละไม้เดียว
//
// ชนะไม่ถึงครึ่ง แต่ได้กำไร เพราะตอนชนะได้ 2 เท่าของตอนแพ้ · เคยแพ้ติดกัน 5 ไม้
// ⚠ เครื่องมือเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน · ผลในอดีตไม่รับประกันอนาคต
//@version=6
strategy("Gold Signal Lab — ตามเทรนด์ใหญ่ รอย่อ", overlay = true,
     default_qty_type = strategy.fixed, default_qty_value = 1,
     initial_capital = 10000, currency = currency.USD,
     commission_type = strategy.commission.cash_per_contract, commission_value = 0.15,
     process_orders_on_close = false, calc_on_every_tick = false)

// ───────────────────────── กติกา ─────────────────────────
// ค่าตั้งต้น = ค่าที่ทดสอบบนทองจริงแล้ว อย่าจูนให้สวยกับอดีต เพราะนั่นคือการฟิตกับข้อมูลเก่า
gR           = "กติกา (ค่าตั้งต้นคือค่าที่ทดสอบแล้ว)"
trendFast    = input.int(20, "เส้นเร็ว กราฟรายวัน (วัน)", minval = 2, group = gR)
trendSlow    = input.int(50, "เส้นช้า กราฟรายวัน (วัน)", minval = 5, group = gR)
pullbackLen  = input.int(20, "เส้นวัดการย่อ กราฟ 4 ชม. (แท่ง)", minval = 2, group = gR)
atrLen       = input.int(14, "ATR (แท่ง)", minval = 2, group = gR)
stopMult     = input.float(2, "ตัดขาดทุน = กี่เท่าของ ATR", minval = 0.5, step = 0.25, group = gR)
targetR      = input.float(2, "ทำกำไร = กี่เท่าของที่เสี่ยง", minval = 0.5, step = 0.25, group = gR)
maxHold      = input.int(36, "ถือได้สูงสุด (แท่ง)", minval = 1, group = gR)
cooldownBars = input.int(6, "พักหลังออกไม้ (แท่ง)", minval = 0, group = gR)
longOnly     = input.bool(false, "เทรดเฉพาะฝั่งซื้อ", group = gR)

// ───────────────────────── เทรนด์ใหญ่ ─────────────────────────
// ดึงค่าของ "เมื่อวาน" ([1]) พร้อม lookahead_on = รูปแบบมาตรฐานที่ไม่วาดใหม่และไม่รู้ราคาปิดวันนี้ล่วงหน้า
[dClose, dFast, dSlow] = request.security(syminfo.tickerid, "D",
     [close[1], ta.ema(close, trendFast)[1], ta.ema(close, trendSlow)[1]], lookahead = barmerge.lookahead_on)
trendUp = dClose > dSlow and dFast > dSlow
trendDn = dClose < dSlow and dFast < dSlow

// ───────────────────────── จังหวะเข้า ─────────────────────────
pb   = ta.ema(close, pullbackLen)
atrV = ta.atr(atrLen)
longSig  = trendUp and close < pb
shortSig = trendDn and close > pb and not longOnly

var int   lastExitBar = na
var int   entryBar    = na
var float sigAtr      = na

if strategy.position_size == 0 and strategy.position_size[1] != 0
    lastExitBar := bar_index
flat   = strategy.position_size == 0
coolOk = na(lastExitBar) or bar_index - lastExitBar >= cooldownBars

if flat and coolOk and (longSig or shortSig)
    sigAtr := atrV
    dist = stopMult * atrV
    if longSig
        strategy.entry("ซื้อ", strategy.long)
        // ระดับชั่วคราวจากราคาปิดแท่งสัญญาณ ใช้กับแท่งที่เข้า แล้วแท่งถัดไปจะคิดใหม่จากราคาเข้าจริง
        strategy.exit("ออก", "ซื้อ", stop = close - dist, limit = close + targetR * dist)
        alert("🟢 ซื้อทองคำ " + syminfo.ticker + " · ราคา " + str.tostring(close, format.mintick)
             + " · ตัดขาดทุน " + str.tostring(close - dist, format.mintick)
             + " · ทำกำไร " + str.tostring(close + targetR * dist, format.mintick), alert.freq_once_per_bar_close)
    else
        strategy.entry("ขาย", strategy.short)
        strategy.exit("ออก", "ขาย", stop = close + dist, limit = close - targetR * dist)
        alert("🔴 ขายทองคำ " + syminfo.ticker + " · ราคา " + str.tostring(close, format.mintick)
             + " · ตัดขาดทุน " + str.tostring(close + dist, format.mintick)
             + " · ทำกำไร " + str.tostring(close - targetR * dist, format.mintick), alert.freq_once_per_bar_close)

// ───────────────────────── ระหว่างถือไม้ ─────────────────────────
if strategy.position_size != 0
    if strategy.position_size[1] == 0
        entryBar := bar_index
    fill   = strategy.position_avg_price
    isLong = strategy.position_size > 0
    stopPx = isLong ? fill - stopMult * sigAtr : fill + stopMult * sigAtr
    risk   = math.abs(fill - stopPx)
    tgtPx  = isLong ? fill + targetR * risk : fill - targetR * risk
    strategy.exit("ออก", isLong ? "ซื้อ" : "ขาย", stop = stopPx, limit = tgtPx)
    if bar_index - entryBar >= maxHold
        strategy.close_all(comment = "ครบเวลา")
else
    entryBar := na

// ───────────────────────── วาดบนกราฟ ─────────────────────────
plot(pb, "เส้นค่าเฉลี่ย 20 แท่ง (จุดเข้า)", color = color.new(#d9ae3b, 0), linewidth = 2)
bgcolor(trendUp ? color.new(color.green, 93) : trendDn ? color.new(color.red, 93) : na, title = "เทรนด์ใหญ่")
plotshape(flat and coolOk and longSig, "สัญญาณซื้อ", shape.triangleup, location.belowbar, color.green, size = size.small)
plotshape(flat and coolOk and shortSig, "สัญญาณขาย", shape.triangledown, location.abovebar, color.red, size = size.small)

if barstate.islast and timeframe.period != "240"
    label.new(bar_index, high, "กติกานี้ทดสอบบนกราฟ 4 ชั่วโมง\nเปลี่ยนกรอบเวลาเป็น 4h ก่อนใช้",
         style = label.style_label_down, color = color.new(color.orange, 0), textcolor = color.black)
