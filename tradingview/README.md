# ใช้ระบบนี้ใน TradingView

ไฟล์ `gold-signal-lab.pine` คือเครื่องยนต์สัญญาณเดียวกับเว็บแอป แต่รันใน TradingView

## ทำไมต้องใช้เวอร์ชันนี้

| | เว็บแอป | TradingView |
|---|---|---|
| ข้อมูลราคา | ต้องหาเอง (PAXG ฟรีแต่ไม่ใช่สปอต · XAU/USD ต้องมี key และจำกัดโควตา) | **ของโบรกเกอร์คุณเอง ไม่มีโควตา** |
| กราฟ | วาดเอง | **กราฟที่คุณคุ้นเคยอยู่แล้ว** |
| ทดสอบย้อนหลัง | มีในตัว | **Strategy Tester ของ TradingView** |
| แจ้งเตือน | ต้องเปิดแท็บค้างไว้ | **เข้ามือถือผ่านแอป แม้ปิดเครื่อง** |
| คำอธิบายภาษาไทย | ✅ ครบทุกปัจจัย | มีตารางสรุปย่อ |

**ใช้คู่กันได้:** เว็บแอปไว้เรียนรู้ว่าทำไม · TradingView ไว้เฝ้าสัญญาณจริง

## วิธีติดตั้ง (2 นาที)

1. เปิด TradingView → เลือกกราฟ **XAUUSD** (หรือ **OANDA:XAUUSD** / **FX:XAUUSD**)
2. เปิด **Pine Editor** (แถบล่างของหน้าจอ)
3. คัดลอกทั้งไฟล์ `gold-signal-lab.pine` มาวางทับ
4. กด **Save** ตั้งชื่ออะไรก็ได้ → กด **Add to chart**

## ตั้งแจ้งเตือนเข้ามือถือ

1. คลิกขวาบนกราฟ → **Add alert**
2. ช่อง Condition เลือก **Gold Signal Lab**
3. เลือก **สัญญาณซื้อ** หรือ **สัญญาณขาย**
4. ติ๊ก **Notify on app** → **Create**

ติดตั้งแอป TradingView บนมือถือแล้วล็อกอินบัญชีเดียวกัน แจ้งเตือนจะเด้งเข้ามือถือ
พร้อมราคาเข้า จุดตัดขาดทุน เป้าหมาย และคะแนน — **ปิดคอมได้เลย**

> แผนฟรีตั้งแจ้งเตือนได้จำนวนจำกัด ถ้าเต็มให้ลบอันเก่าออกก่อน

## อ่านผลทดสอบย้อนหลัง

กดแท็บ **Strategy Tester** ด้านล่าง ดู 2 ตัวเลขนี้เป็นหลัก:

- **Profit Factor** — เกิน 1.3 ถือว่าใช้ได้
- **Percent Profitable** — อย่าดูตัวเดียว ต้องดูคู่กับ Ratio Avg Win/Avg Loss
  (ชนะ 40% ที่อัตราส่วน 2:1 คือกำไร ส่วนชนะ 65% ที่ 0.4:1 คือขาดทุน)

**สำคัญ:** เปลี่ยนค่าใน Settings ไปเรื่อย ๆ จนตัวเลขสวยคือการจูนให้พอดีกับอดีต
ใช้กับอนาคตไม่ได้ ให้ตั้งค่าครั้งเดียวแล้วดูว่ามันทำงานยังไงกับช่วงเวลาที่ไม่ได้จูน

## ค่าที่ปรับได้

ตั้งค่าทั้งหมดอยู่ในหน้า Settings ของ indicator แบ่งเป็น 3 กลุ่ม:

- **เกณฑ์สัญญาณ** — คะแนนขั้นต่ำ, เกณฑ์ ADX, ความกว้างจุดตัดขาดทุน, เป้าหมาย, ความเสี่ยงต่อไม้
- **ตัวกรอง** — กรอบเวลาใหญ่ต้องเห็นตรงกันไหม, กรองความผันผวน, จำกัดช่วงเวลา
- **น้ำหนักปัจจัย** — ปรับน้ำหนักทั้ง 12 ปัจจัยได้ (รวมกันได้ 120 ในค่าเริ่มต้น)

น้ำหนักและค่าตั้งต้นตรงกับเวอร์ชันเว็บทุกตัว — มีเทสต์อัตโนมัติคอยตรวจไม่ให้สองเวอร์ชันเพี้ยนจากกัน

## ข้อจำกัดเทียบกับเวอร์ชันเว็บ

- ไม่มีการหาจุดเข้า-ออกที่ดีที่สุดอัตโนมัติ (Pine ทำ optimizer ในตัวไม่ได้)
  → ใช้เว็บแอปหาค่าที่ดีก่อน แล้วเอามาใส่ที่นี่
- ไม่มีคำบรรยายกราฟภาษาไทยแบบยาว มีแค่ตารางสรุปมุมขวาบน
- แนวรับ-แนวต้านใช้ swing ล่าสุดคู่เดียว ไม่ได้จับกลุ่มเป็นโซนเหมือนเวอร์ชันเว็บ

## ยังไม่ได้ทดสอบกับคอมไพเลอร์จริง

ไฟล์นี้เขียนตามไวยากรณ์ Pine v6 และผ่านการตรวจโครงสร้างแล้ว
แต่ **ยังไม่เคยคอมไพล์ใน TradingView จริง** เพราะสภาพแวดล้อมที่พัฒนาเข้าถึงไม่ได้
ถ้าขึ้น error ตอน Add to chart ให้ส่งข้อความ error มา จะแก้ให้ทันที
