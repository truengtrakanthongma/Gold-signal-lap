# Gold Signal Lab — ระบบตามเทรนด์ทองคำ

**เปิดใช้งาน:** https://truengtrakanthongma.github.io/Gold-signal-lap/

ระบบสัญญาณทองคำ (XAU/USD) ที่มี**กติกาเดียว** ผ่านการทดสอบบนข้อมูลทองจริง 4 ปี
หน้าเว็บ บอท Discord และสคริปต์ TradingView ใช้กติกาชุดเดียวกันทุกตัว

> เครื่องมือเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน · ผลในอดีตไม่รับประกันอนาคต

## กติกา

| ขั้น | กราฟ | เงื่อนไข |
|---|---|---|
| 1. เทรนด์ใหญ่ | รายวัน (แท่งที่ปิดแล้ว) | **ขาขึ้น** = ราคาปิด > EMA50 **และ** EMA20 > EMA50 · **ขาลง** = กลับด้าน · นอกนั้น = ไม่เทรด |
| 2. จังหวะเข้า | 4 ชั่วโมง | ขาขึ้น + ราคาปิด**ย่อลงใต้** EMA20 → ซื้อ · ขาลง + ราคาปิด**เด้งเหนือ** EMA20 → ขาย |
| 3. แผน | 4 ชั่วโมง | เข้าที่ราคาเปิดแท่งถัดไป · ตัดขาดทุน **2 × ATR(14)** · ทำกำไร **2 เท่าของที่เสี่ยง** |
| 4. บริหารไม้ | — | ถือไม่เกิน 36 แท่ง (6 วัน) · ออกไม้แล้วพัก 6 แท่ง (24 ชม.) · ถือทีละไม้เดียว |

ด่านที่บังคับทุกทาง (ปิดไม่ได้): **ตลาดทองปิด** (เสาร์-อาทิตย์ และพักรายวัน) · **ข้อมูลค้าง/ราคาไม่ขยับ** ·
**ทุนไม่พอ** — ถ้าไม้เล็กสุดที่โบรกรับเสี่ยงเกิน 10% ของทุน จะไม่มีแผนให้กด

โค้ดของกติกาอยู่ที่ [`js/system.js`](js/system.js) ไฟล์เดียว

## ผลทดสอบบนทองจริง

ข้อมูล XAU/USD รายนาที 2022–2025 (1.37 ล้านแท่ง) รวมเป็นกราฟ 4 ชม. และรายวัน · หักค่าสเปรด $0.30 + สลิปเพจ $0.10 ทุกไม้

| | |
|---|---|
| จำนวนไม้ | 166 (ราว 3.6 ไม้/เดือน) |
| อัตราชนะ | 45% (ช่วงที่เป็นไปได้ 38–53%) |
| ได้เฉลี่ยต่อไม้ | **+0.28 เท่าของเงินที่เสี่ยง** · กำไรรวม +46R |
| รายปี | 2022 +0.16R · 2023 +0.18R · 2024 +0.35R · 2025 +0.40R — **กำไรทุกปี** |
| แพ้ติดกันมากสุด | 5 ไม้ · ติดลบลึกสุด 7.2R |
| เดือนที่ขาดทุน | 18 จาก 46 เดือน · เคยนาน 260 วันกว่าจะทำกำไรสูงสุดใหม่ |
| ฝั่ง | ซื้อ 126 ไม้ +0.39R/ไม้ · ขาย 40 ไม้ −0.07R/ไม้ |

**ชนะไม่ถึงครึ่งแต่ได้กำไร** เพราะตอนชนะได้ 2 เท่าของตอนแพ้ (จุดคุ้มทุนอยู่ที่ชนะราว 35%)
ไม่มีระบบไหนชนะทุกไม้ — ระบบนี้ต้องรับการแพ้ติดกันหลายไม้ให้ได้

### ทำไมถึงเชื่อตัวเลขนี้ได้มากกว่าระบบเดิม

- **เทียบระบบเดิม** (12 ตัวชี้วัด กราฟ 15 นาที) บนข้อมูลชุดเดียวกัน: 4,091 ไม้ **−0.042R/ไม้** ขาดทุนแทบทุกปี
  ดีกว่าโยนเหรียญ (−0.059R) แค่นิดเดียว — เสียหนักสุดจากการเปิดขายสวนตลาดขาขึ้น 1,927 ครั้ง (−176R)
  และคะแนนความมั่นใจสูงไม่ได้ชนะมากกว่าคะแนนต่ำ
- **ความทนทาน**: เปลี่ยนค่าทีละอย่าง 23 แบบ (SL 1.5–3 ATR · เป้า 1–3R · เส้นเทรนด์ 10/30–30/100 วัน ·
  สเปรดแพงขึ้นถึง 4 เท่า · ตั้งเวลาแท่งแบบโบรก GMT+2/+3) — **กำไรทั้ง 23 แบบ** กำไรทุกปี 17 แบบ
- **ตัวควบคุม**: สุ่มเข้าตอนไหนก็ได้ในเทรนด์ใหญ่ได้ +0.24R — แปลว่า**กำไรส่วนใหญ่มาจากการตามเทรนด์**
  การรอย่อช่วยเพิ่มอีกนิด (ดีกว่าการสุ่ม 90% ของรอบ) และทำให้รอดปี 2023 ที่ตลาดออกข้าง
- **ไม่มองอนาคต**: ทดสอบว่าการตัดสินที่แท่งใดไม่เปลี่ยนเมื่อมีข้อมูลหลังจากนั้นเพิ่มเข้ามา
  และบนตลาดสุ่มเดินต้องไม่ได้กำไรผิดธรรมชาติ

ผลละเอียดทุกไม้อยู่ใน [`js/reference.js`](js/reference.js) (สร้างจากโค้ดจริง มีเฉพาะผลที่คำนวณแล้ว ไม่มีราคาดิบ)

### ข้อจำกัดที่ต้องรู้

- 4 ปีนี้ทองขึ้นจาก ~1,800 เป็น ~4,300 ดอลลาร์ ช่วงนี้เป็นใจกับการตามเทรนด์ขาขึ้น — ฝั่งขายยังไม่มีหลักฐานว่าได้เปรียบ
- ผลจริงในอนาคตมักแย่กว่าผลทดสอบ ให้คาดไว้ต่ำกว่านี้
- ราคาในเว็บมาจากเหรียญทอง (PAXG/XAUT) ซึ่งต่างจากราคาทองของโบรกเล็กน้อย — ถ้าอยากได้ราคาของโบรกเอง ใช้ TradingView
- **ระยะตัดขาดทุนบนกราฟ 4 ชม. กว้าง** — ปลายปี 2025 ที่ทองราว 4,000–4,300 ดอลลาร์ ระยะ 2×ATR อยู่ราว 58–80 ดอลลาร์ต่อออนซ์
  บัญชีที่ไม้เล็กสุดคือ 1 ออนซ์ (0.01 ล็อตของ 100 ออนซ์) ต้องมีทุนราว 3,000–4,000 ดอลลาร์ถึงจะเสี่ยง 2% ต่อไม้ได้
  ทุนน้อยกว่านั้นให้ใช้บัญชีที่ 1 ล็อต = 1 ออนซ์ (ตั้งได้ในหน้าตั้งค่า) — ระบบจะไม่ให้แผนถ้าไม้เล็กสุดเสี่ยงเกิน 10% ของทุน

## บอท Discord (เตือนแม้ปิดเครื่อง · ฟรี)

รันบน GitHub Actions ทุก 15 นาที ใช้ `js/system.js` ตัวเดียวกับหน้าเว็บ

1. สร้าง webhook ในห้อง Discord (ตั้งค่าห้อง → Integrations → Webhooks) แล้วคัดลอก URL
2. รีโปนี้ → **Settings → Secrets and variables → Actions → New repository secret**
   ชื่อ `DISCORD_WEBHOOK_URL`
3. แท็บ **Actions** → *บอทเฝ้าสัญญาณ* → **Run workflow** → ติ๊ก **test ping** → ต้องมีรายงานสถานะเด้งเข้าห้อง

ตั้งค่าได้ที่ **Variables** (ไม่ต้องแก้โค้ด):

| ตัวแปร | ค่าตั้งต้น | ความหมาย |
|---|---|---|
| `BOT_ACCOUNT` | 1000 | ทุน (USD) |
| `BOT_RISK_PCT` | 2 | ยอมเสียต่อไม้ (% ของทุน) |
| `BOT_CONTRACT_SIZE` | 100 | 1 ล็อต = กี่ออนซ์ |
| `BOT_MIN_LOT` / `BOT_LOT_STEP` | 0.01 | ล็อตเล็กสุด / ขั้นล็อต |
| `BOT_SPREAD` | 0.30 | ค่าสเปรดของโบรก (USD/ออนซ์) |
| `BOT_SIDES` | both | `long` = เทรดเฉพาะฝั่งซื้อ |
| `BOT_SOURCES` | kraken_paxg,… | ลำดับแหล่งราคาที่ลอง |

`BOT_THRESHOLD`, `BOT_INTERVAL`, `BOT_EXIT_STYLE`, `BOT_ENTRY_MODE` ของระบบเดิมไม่มีผลแล้ว (บอทจะบอกในล็อก ลบทิ้งได้)

สิ่งที่บอทกันไว้: ตลาดปิด = ไม่เตือน · แท่งล่าสุดเก่าเกิน = ไม่เตือน · ทุนไม่พอ = บอกว่ามีสัญญาณแต่ไม่ส่งราคาเข้า/SL/TP ·
เตือนแต่ละสัญญาณครั้งเดียว · ตั้งค่าผิด = หยุดพร้อมบอกว่าผิดตรงไหน · รันเทสต์ก่อนทุกรอบ ·
หยุดเองถ้ารีโปไม่ได้เป็นสาธารณะ (กันเสียค่า Actions)

| `js/reference.js` | ผลทดสอบ 4 ปี (สร้างอัตโนมัติจาก system.js — ถ้าแก้กติกาแล้วไม่สร้างใหม่ เทสต์จะฟ้อง) |
| `js/indicators.js` | EMA / ATR |

| `js/macro.js` | เวลาตลาดทอง · ราคาทองไทย |
