# ทำซ้ำผลทดสอบ 4 ปี

ตัวเลขทุกตัวใน `js/reference.js` (และที่หน้าเว็บ/บอทโชว์) สร้างจากสคริปต์ในโฟลเดอร์นี้ ด้วยกติกาจาก `js/system.js` ตัวเดียวกับที่ให้สัญญาณจริง

```bash
# 1. ข้อมูล XAU/USD รายนาทีของ HistData.com (ปี 2022-2025) จากที่เก็บสาธารณะ
git clone --depth 1 --filter=blob:none --sparse https://github.com/tiumbj/M1_XAUUSD ../data-src/M1_XAUUSD
git -C ../data-src/M1_XAUUSD sparse-checkout set --no-cone '/DAT_MT_XAUUSD_M1_202[2-5].csv'

# 2. รวมเป็นแท่ง 15 นาที / 1 ชม. / 4 ชม. / รายวัน (เก็บที่ research/.cache ไม่ขึ้น git)
HISTDATA_DIR=../data-src/M1_XAUUSD node --max-old-space-size=4096 research/build-data.mjs

# 3. เดินกติกา สร้างผลอ้างอิง + ตารางความทนทาน + ตัวควบคุมสุ่มเข้า
node --max-old-space-size=4096 research/gen-reference.mjs
```

ผลต้องได้ `js/reference.js` ตรงกับที่อยู่ในรีโปทุกไบต์

| ไฟล์ | หน้าที่ |
|---|---|
| `build-data.mjs` | แปลงเวลา HistData (EST คงที่ = UTC−5) เป็น UTC แล้วรวมแท่ง · ไม่มีปริมาณซื้อขายจริง จึงใช้ผลรวมช่วงราคารายนาทีแทน |
| `gen-reference.mjs` | รันกติกาจริง · เปลี่ยนค่าทีละอย่าง 23 แบบ · สุ่มเข้าในเทรนด์ 200 รอบเป็นตัวเทียบ |
| `sim.mjs` | ตัวจำลองอิสระแบบง่าย ใช้กับตัวควบคุมสุ่มเข้า |
