# ใช้ระบบนี้ใน TradingView

`gold-signal-lab.pine` คือกติกาเดียวกับเว็บแอปและบอท Discord (ดู [`js/system.js`](../js/system.js))
แต่รันใน TradingView — ได้ราคา XAUUSD จริงจากโบรกเกอร์ของคุณ ทดสอบย้อนหลังใน Strategy Tester และแจ้งเตือนเข้ามือถือ

**ต้องใช้บนกราฟ 4 ชั่วโมง** (กติกาทดสอบมาบนกรอบนี้ สคริปต์จะขึ้นป้ายเตือนถ้าใช้กรอบอื่น)

## ติดตั้ง

1. เปิด TradingView → กราฟ **XAUUSD** → กรอบเวลา **4h**
2. เปิด **Pine Editor** → วางโค้ดทั้งไฟล์ทับของเดิม → **Save** → **Add to chart**
3. แท็บ **Strategy Tester** ล่างจอ = ผลทดสอบย้อนหลังบนราคาของโบรกคุณ

ผลที่ควรเห็นโดยประมาณ: ราว 3–4 ไม้ต่อเดือน · ชนะราว 45% · Profit Factor ราว 1.5

## แจ้งเตือนเข้ามือถือ

ไอคอนนาฬิกาปลุก (Alert) → Condition: **Gold Signal Lab** → **Any alert() function call** → ติ๊ก **Push notification** → Create

## อย่าจูนค่าให้ผลสวยที่สุด

ค่าตั้งต้นคือค่าที่ทดสอบแล้วและทนต่อการเปลี่ยนค่า การไล่ปรับจนกราฟกำไรสวยคือการฟิตกับอดีต ซึ่งมักพังทันทีที่ใช้จริง
